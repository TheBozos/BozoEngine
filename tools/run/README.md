# bozo-run

Phase 2's runner: TMB's code generated by `bozo-recomp`, on BozoEngine's own EE kernel, dispatcher and cycle model
([`docs/specs/kernel.md`](../../docs/specs/kernel.md)), with every library BozoEngine does not implement yet
answered from a call log ([`docs/specs/calllog.md`](../../docs/specs/calllog.md)). Every record of the log is made
again and checked in lockstep; the per-frame reference record (PS2XREF1,
[`docs/specs/harness.md`](../../docs/specs/harness.md) section 6) is written and compared with the reference
build's.

## Build

```sh
export PATH=/c/msys64/ucrt64/bin:$PATH
cmake -S . -B build -G Ninja -DBOZO_TMB_ELF=D:/TMB_Recomp/build/us_probe/SCUS_971.01 \
      -DBOZO_CALLLOGS=D:/BozoCaptures/tmb/calllog [-DBOZO_CAPTURES=D:/BozoCaptures/tmb]
cmake --build build
```

`bozo-calllog-tool externals` lists the logs' external addresses (every named stub and every override, from their
NAME and OVRD chunks, merged with the captures' list when `BOZO_CAPTURES` is set); `bozo-recomp` generates TMB's code
with them into `build/tmb_gen` (cached, never committed); `bozo-run` links it with the runtime (`runtime/`) and the
log-backed host (`log_host.cpp`).

## Run

```sh
build/tools/run/bozo-run D:/BozoCaptures/tmb/calllog/boot.clg --ref reference/tmb/records/boot.ref --out build/boot.ref
python tools/capture/ref_compare.py build/boot.ref reference/tmb/records/boot.ref --ignore draws,sound
```

| Option | What |
|---|---|
| `--ref <run.ref>` | compare each frame's record with the reference's (ram, scratchpad, calls, threads, eeCycle) and print the first frame each field differs at |
| `--out <out.ref>` | write BozoEngine's PS2XREF1 record (draws and sound 0: no renderer or mixer yet) |
| `--frames n` | stop after n frames (default: the log's frame limit) |
| `--elf <path>` | the game's executable (default: the one the build was generated from); its XXH64 is checked against the log's |
| `--max-errors n` | go on after a cycle divergence (the cycle is resynced to the log's) until the n-th; anything else stops the run |
| `--trace-from <record>` | print every record matched from that record index on |
| `--trace-checkpoints` | with `--trace-from`: also every checkpoint passed (where it goes on, the cycle, the charge) and every dispatcher start |
| `--quiet` | only the summary |

The exit status is 0 when the whole log was made again with no divergence and every frame equals the reference.

## A divergence

The first record that differs stops the run:

```
DIVERGENCE 1: stub 0x21d0b8: cycle 30445672635 (log 30445672539, +96); checkpoints since the last out-call: 98 (log 86)
  log:  #18297744 CALL f5773 c30445672539 s10068856 t1 ckp86 pc 0x21d0b8 stub 0x21d0b8 ra 0x1d116c ...
  here: frame 5773, cycle 30445672635, seq 10068856, thread 1 depth 0, pc 0x21d0b8, sp 0x8ff230, 98 checkpoints ...
```

`log` is the record (its index in the file, frame, cycle, seq, thread, checkpoints and pc, then its fields) and `here`
BozoEngine's state. `calllog_read.py <log> list --frames A-B` and `show <index>` show the records around it; rerun
with `--trace-from <index - k> --trace-checkpoints` to see BozoEngine's checkpoints in the same stretch.
